# 后台信息架构与功能归属

本文档用于约束家长管理平台和超级后台的功能边界。新增功能前先判断数据归属，再决定页面位置，避免同一业务被拆散到多个入口。

## 1. 归属原则

| 数据范围 | 负责后台 | 判断标准 |
| --- | --- | --- |
| 全平台共享 | 超级后台 | 修改后会影响所有家庭，例如汉字、古诗、星宠素材、模型密钥和平台功能开关 |
| 单个家庭 | 家长端 | 只影响当前家庭，例如家庭自定义任务分类、星愿规则和家庭 AI 建议 |
| 单个孩子 | 家长端 | 只影响当前孩子，例如任务安排、学习参数、学校进度、星宠照顾参数和登录设备 |
| 跨家庭统计 | 超级后台 | 需要查看全部家庭、全部孩子或系统性能的数据 |

前端隐藏按钮不能代替权限控制。全平台资源的写接口只允许超级管理员访问；家长端只能读取资源并维护自己孩子的配置。

## 2. 家长端导航

### 工作台

- 成长总览：学习掌握、任务完成、星星收支和简洁建议。
- 孩子管理：孩子切换、资料、目标、登录代码、设备和退出登录集中在一个页面。

### 任务中心

- 任务配置：任务列表、周历、家庭自定义分类和新增编辑任务。
- 任务记录：任务尝试、完成时间、退款和奖励回退。

### 学习管理

- 汉字学习：学校优先清单、学习参数、只读基础字库。
- 古诗学习：学校优先清单、学习参数、只读古诗资源库。
- 时钟学习、凑十训练、数学练习：各自独立设置和统计，不放进新增任务表单。

学校优先清单必须独立展示排序、数量和移除操作。不能要求家长进入全量字库或诗库逐项查找标记。

### 激励与奖励

- 星愿管理、兑换记录、星星流水、排行榜和航图集中在同一业务组。

### 星宠与智能

- 星宠管理：伙伴照顾、升级红包、小屋背景使用页内标签分区。
- AI 助手：只保留当前家庭的建议和分析；平台模型密钥不在家长端出现。

## 3. 超级后台导航

### 运营工作台

- 运营概览：全平台核心指标。
- 家庭与账号：家庭和家长账号维护、家庭数据概览。
- 孩子账号：跨家庭孩子查询、登录代码、状态和设备退出。

### 学习内容

- 汉字资源库：全局汉字增删改、图片和音频上传、MiniMax 生成。
- 古诗资源库：全局古诗增删改、图片和音频上传、MiniMax 生成。

资源页默认只展示列表和筛选；点击新增或编辑后才打开对话框。媒体操作跟随资源编辑，不常驻占用列表空间。

### 星宠运营

- 成长与旅行：全平台成长、旅行目的地和规则。
- 形态与动画：星宠状态、房间主题专属动画和素材上传。
- 星宠话术：场景话术、试听和语音生成。

### AI 与模型

- DeepSeek 配置、MiniMax 配置、模型调用统计分别独立。
- 平台密钥只由超级管理员维护，家庭端不提供修改入口。

### 系统运维

- 性能诊断、平台功能开关、审计日志。

## 4. 新增与编辑交互

- 浏览态默认是列表、筛选、统计和详情。
- 新增、编辑使用对话框或独立详情页，不在列表旁长期放置表单。
- 删除、停用、重置代码和设备退出等高风险操作需要二次确认。
- 保存成功后关闭编辑界面并刷新列表；失败时在当前编辑界面显示明确错误。
- 手机端对话框使用可滚动内容区，列表转为卡片或保留横向滚动，不能压缩字段到不可读。

## 5. 后续功能放置检查

新增功能前依次回答：

1. 修改是否会影响其他家庭？是则进入超级后台。
2. 是否属于孩子账号生命周期？是则进入孩子管理。
3. 是否属于某个学习功能的参数、进度或学校计划？是则进入对应学习模块的二级标签。
4. 是否属于任务执行、奖励或消费？分别进入任务中心或激励与奖励。
5. 是否只是技术诊断或平台配置？进入超级后台系统运维，不进入家长端。
