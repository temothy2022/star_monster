# 数学练习任务：题型、生成与平台整合方案

## 1. 产品目标

面向 5 岁儿童，在 iPad 上完成小学一年级入门数学练习。家长可以在任务平台中选择“数学练习”，设置总题数，并把题数自由分配到 49 个题型。儿童端不调用系统键盘，所有答案通过大尺寸数字、符号、选项、多选或排序控件完成。

本实现遵循三条硬规则：

1. 答案由结构化参数先行计算，界面只负责展示这些参数。
2. 会影响答案的数量、顺序、遮挡、划去、数位和立方体结构全部由程序绘制。
3. AI 图片仅用于已经审核的单个小动物、食物和文具贴图，不让 AI 生成需要计数的整幅题图。

## 3. 视觉资源与生成职责

### 3.1 可复用美术资源

- 单体动物：小鸡、小狗；透明背景、正面或轻微侧面、轮廓清楚。
- 单体物品：苹果、铅笔；用于计数、分组、加减和应用题。
- 装饰元素：爪印、星星、彩带、浅色网格背景，可用 CSS 或现有平台资产。

贴图必须是“一个文件只表示一个对象”。程序根据答案复制贴图并控制行列、分组和叉号，从而保证孩子看到的数量与标准答案永远一致。

### 3.2 必须程序绘制的视觉

- 行列计数、袋子/盘子分组、括号总数、划去对象。
- 数字序列框、相邻数框、数的分合、算式格。
- 十位个位小棒、计数器珠子、数位标签。
- 队列编号、左右箭头、二维方格、多条件逻辑表。
- 大小/高矮/长短缩放关系和轻重跷跷板状态。
- 正方体：生成连通三维坐标集合，按坐标计数，再投影为 SVG 顶面、左面和右面。

## 4. 答题与反馈规则

- 单空和多空：0–9 大按钮，最多两位；多空题可点选空格，并用“下一格”前进。
- 符号：提供 `+`、`-`、`>`、`<`、`=` 的独立按钮。
- 单选和多选：大卡片选项，选中态使用边框和颜色双重提示。
- 排序：依次点选数字形成排序结果，可一键重新排列。
- 第一次答错：保留原题，给予简短鼓励并允许重试。
- 第二次答错：显示正确答案和一行解释，将该题记为已完成后进入下一题。
- 全部完成：调用原有任务完成流程并发放任务星星，不额外复制一套奖励逻辑。

## 5. 家长配置规则

- 新任务类型：`MATH_PRACTICE`。
- “学习内容 > 数学练习”集中设置总题数，并在六大分类中展开 49 个题型，通过加减步进器分配题数；旧版 P02 配置自动并入 P01。
- 分配数总和必须等于总题数，否则禁止保存并显示差额。
- 任务配置只维护出现日期、奖励和重复规则；孩子的所有数学练习任务共用一份学习设置。
- 系统把统一设置同步到数学任务模板；每天生成任务时再把配置快照写入每日任务。
- 历史每日任务优先读取快照；旧数据没有快照时兼容读取模板配置。

## 6. 数据与接口流程

1. `MathPracticeSettings` 保存孩子统一的总题数和题型数量，`MathPracticeConfig` 保存同步到任务模板的执行配置。
2. 每日任务保存 `mathPracticeConfigSnapshot`，避免家长随后改模板导致当天练习变化。
3. 开始任务时，服务端按每日任务 ID、尝试 ID 和题目序号组合种子，生成可复现的题目。
4. 客户端只收到不含标准答案的 `MathQuestion`。
5. 提交答案后，服务端重新用相同种子生成标准题并校验，保存 `MathPracticeQuestionAttempt`。
6. 全部题目结算后完成 `MathPracticeSession`，再进入现有 `completeTaskAttempt` 奖励流程。

## 7. 验收清单

- 49 个题型都能在静态预览目录中单独打开并随机换题。
- 同一个种子生成完全相同的问题和答案；不同种子有足够变化。
- 所有数量图、叉号图、数位图和正方体图可由生成参数反向核算答案。
- 儿童端全程不弹系统键盘；iPad 横屏按钮触控区域不小于约 52–64 px。
- 家长配置总数不匹配时不能保存。
- 第一错可重试、第二错揭示答案、未完成全部题目不能完成任务。
- 普通任务、识字任务、时钟任务和凑十任务的既有流程不受影响。
- 数据库迁移、类型检查、单元测试和生产构建全部通过后方可发布。
