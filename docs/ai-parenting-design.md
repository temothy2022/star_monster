# AI 育儿助手设计与提示词规范

## 目标

AI 是家长的决策支持工具，不是孩子的评判者，也不是自动执行人。所有功能采用同一条边界：

1. AI 读取匿名化的必要数据并生成结构化草案。
2. 服务端使用 Zod 和业务规则校验字段、归属、时长、时间窗与重叠。
3. 家长在界面中阅读理由和提醒。
4. 只有家长明确点击“确认并应用”后才写入任务或排班。
5. 星星经济审计只给建议，永不自动改星或改兑换价格。

## 研究依据与产品转译

- CDC 的 5 岁里程碑列出简单家务、故事理解、计数，以及在非屏幕活动中通常能保持 5–10 分钟注意等常见表现。这些是群体性的里程碑，不作为诊断标准。因此产品默认建议短任务，但允许家长根据孩子状态调整，不把 10 分钟做成硬限制。
  - https://www.cdc.gov/act-early/milestones/5-years.html
- 美国儿科学会 HealthyChildren 建议学龄前儿童可以承担简单家庭任务，并强调固定职责、清晰预期和可见的任务表。产品因此要求“孩子能听懂的目标”和“可观察的完成标准”。
  - https://www.healthychildren.org/English/family-life/family-dynamics/communication-discipline/Pages/Chores-and-Responsibility.aspx
- 哈佛儿童发展中心的执行功能活动指南强调 3–5 岁儿童的选择、游戏、规则和稳定日常结构。产品因此优先提供有限选择、稳定例行与自由玩耍留白。
  - https://developingchild.harvard.edu/resources/handouts-tools/activities-guide-enhancing-and-practicing-executive-function-skills/
- UNICEF 的积极育儿资料强调一致性、正向关系、给孩子选择和肯定良好选择。提示词禁止羞辱、威胁、比较和扣除已经获得的星星。
  - https://www.unicef.org/parenting/child-care/how-discipline-your-child-smart-and-healthy-way
- 自主支持与学生动机、投入和胜任感的研究综述支持把自主性、胜任感和亲子联结作为任务设计目标，而不是只追求服从。
  - https://doi.org/10.1007/s10648-015-9329-z
- 间隔学习和提取练习有广泛学习科学证据，但没有适合所有 5 岁儿童、所有材料的固定“神奇间隔”。排班器使用最小间隔、目标次数和最近表现作为可调整参数。
  - https://doi.org/10.1038/s44159-022-00089-1
  - https://www.frontiersin.org/journals/education/articles/10.3389/feduc.2019.00005/full

## 三类 AI 输出

### 任务顾问

输入：

- 家长的自然语言情境、目标和限制；
- 当前任务的分类、时长、频率和星星；
- 当前星愿价格。

输出：

- 是否适合作为任务、置信度和仍需家长决定的问题；
- 标题、分类、任务类型、时长、频率、星星；
- 学习/复习类型、排班次数、最小间隔；
- 孩子友好目标、完成标准、家长支持方式；
- 理由、替代方案、风险提醒和所用原则。

家长自由文本仅在当次请求中发送给 DeepSeek，不保存在建议记录中。

### 星星与兑换校准

输入：

- 启用任务的时长、频率、基础/加成星星；
- 近 30 天完成数据；
- 当前星愿价格。

输出：

- 0–100 的整体一致性评分；
- 预计每周星星区间；
- 每个星愿的大致可达周数；
- 任务或星愿的具体观察、建议和建议值。

评分用于发现相对失衡，不表示科学量表或孩子能力评分。

### 智能排班

输入：

- 家长设置的每周可用时间窗；
- 每日总任务上限、单次连续上限、任务间休息；
- 明确勾选“参与 AI 排班”的任务；
- 每个任务的练习类型、目标次数、最小间隔和预计时长。

输出：

- 具体星期、开始分钟、任务和时长；
- 每个任务的周频率；
- 家长执行建议和提醒。

服务端拒绝以下结果：未知任务、时间重叠、超出可用时间、时长与后台设置不一致、超过每日/连续上限、休息不足、周频率与具体排班不一致。

## 提示词与返回契约

- 提示词版本：`parenting-cn-v1.0.0`
- 提示词：`apps/api/src/ai/prompts.ts`
- Zod 返回契约：`apps/api/src/ai/schemas.ts`
- DeepSeek JSON 客户端：`apps/api/src/services/deepseek-service.ts`
- 排班二次校验：`apps/api/src/services/schedule-validation.ts`

DeepSeek 使用 JSON Output；系统提示中明确包含 `json` 和完整 JSON 示例，返回后仍由 Zod 严格解析。空响应或无效 JSON 最多重试一次，不会使用半结构化文本兜底写库。

## 隐私与密钥

- API Key 使用 AES-256-GCM 加密；数据库只额外保存末四位用于辨识。
- 主加密密钥来自 `AI_CONFIG_ENCRYPTION_KEY`，不得提交到 Git；生产环境应使用密钥管理服务注入。
- 更换主加密密钥前必须迁移已有密文，否则旧配置无法解密。
- 完整 API Key 不通过 API 返回、不写日志、不进入审计 metadata。
- 不向 DeepSeek发送孩子登录码、昵称、家庭名称、设备、IP、地址或学校。
- 家长自由文本会发送给 DeepSeek，因此界面明确提醒不要输入身份信息。
- AI 调用按家庭、用户和功能进行小时级限流。

## 不处理的场景

AI 不提供发育、心理、语言、睡眠、营养或疾病诊断。出现安全风险、持续强烈情绪、发育担忧或医疗问题时，界面与提示词要求家长咨询儿科医生或相应合格专业人员。
