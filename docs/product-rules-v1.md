# 星宠成长基地 V1 产品规则

状态：已确认并冻结。除非后续明确修改，开发与验收均以本文件为准。

## 1. 产品与角色

- 产品是网页应用，主要运行在 iPad，也支持桌面浏览器。
- 孩子端、家长端后台、超级管理后台是三个独立前端，共用一套 API 和数据库。
- 一个家长可以管理多个孩子；每个孩子拥有独立账号、登录代码、任务、星星、星愿和足迹。
- 超级管理员仍可代为创建家庭和家长；家长端同时开放邮箱自助注册，当前阶段不要求短信验证。
- 家长注册后可以自行创建多个孩子，每个孩子生成独立探险代码；超级管理员账号不开放注册。
- 孩子端提供个人中心，可修改昵称和头像、退出登录或切换账号；航图及星球点亮提醒已纳入当前版本。

## 2. 登录与首次使用

- 孩子使用 8 位大写字母与数字登录代码登录，排除容易混淆的字符。
- 登录代码长期有效，直到管理员重新生成。
- 孩子会话采用 365 天滑动有效期的安全 Cookie。
- 重新生成登录代码不会强制退出已经登录的设备；管理员可以查看设备并执行“全部退出”。
- 孩子首次登录依次完成：选择星宠、确认昵称、任务介绍、航程介绍。
- 可选星宠为豆芽、泡泡、团团、米露、闪闪。每只星宠有普通、专注、庆祝三种形态。
- 首次选择结果保存到孩子档案；孩子端所有页面必须通过统一星宠资源映射显示同一只星宠，不能在页面中写死某一只。
- 普通形态用于任务列表、足迹等陪伴场景；专注形态用于进行中场景；庆祝形态用于完成和奖励场景。
- 昵称限制为 2–9 个字符。完成后记录 `onboardingCompletedAt`，以后直接进入任务页。
- 家长可以修改昵称、重置首次引导；孩子也可以在个人中心修改自己的昵称和头像。
- 家长和超级管理员使用用户名、密码登录。

## 3. 任务分类与配置

预设分类：

- 语文（含阅读、汉字和古诗）
- 数学
- 英语
- 运动（含体育训练）
- 生活习惯（含家务和整理）
- 综合任务（含跨学科作业、音乐和其他任务）

数据库继续保留旧枚举值以兼容历史数据，但后台新建和编辑任务只能使用以上六类。旧分类按“阅读→语文、体育→运动、家务/整理→生活习惯、音乐→综合任务”统一展示。

任务配置包含：所属孩子、标题、分类、任务图标、普通/限时、建议时长或限时时长、基础星星、提前完成加成、循环方式、排序和启用状态。

- 图标只能从预设素材中选择，不支持上传自定义图标。
- 循环任务支持每天、仅工作日（周一至周五）、指定星期。
- 一次性任务仅在指定日期出现一次。
- 新增循环任务时，如果当天符合计划，则立即生成当天任务。
- 修改任务模板只影响未来生成的任务；当天任务保留生成时的快照。
- 停用或归档模板不删除历史数据，只影响未来任务。
- 每天以 `Asia/Shanghai` 时区零点结算并生成当天任务。
- 前一天未完成的循环任务不会顺延；符合计划时第二天生成新的任务实例。

## 4. 任务状态和执行规则

- 每个孩子同一时间只能有一个进行中或已暂停的任务。
- 当日任务状态：待开始、进行中、已暂停、已完成、已过期。
- 尝试记录状态：进行中、已暂停、已完成、超时、已放弃。
- 点击开始时，如果已有进行中或暂停任务，则进入该任务而不是开启新任务。
- 刷新或关闭网页不会暂停任务；只有孩子主动点击暂停才会暂停。
- 暂停期间普通任务不累计执行时长，限时任务停止倒计时。
- 已暂停任务仍占用唯一进行中名额。
- 放弃任务不获得星星，当日任务回到待开始，可以重新挑战。
- 每次重试都会新建尝试记录；限时任务从完整时限重新开始。

普通任务由孩子自行点击完成，记录实际执行时长并发放一次奖励。

限时任务以服务器时间为准：

- 时限内完成：获得基础星星。
- 完成时剩余时间大于等于模板设置的提前阈值：额外获得加成星星。
- 倒计时结束仍未完成：进入失败页，不发放星星，当日任务回到待开始，可以重试。

跨越午夜时：

- 待开始任务变为已过期。
- 进行中或暂停任务终止。
- 限时挑战按失败处理。
- 新的一天按计划生成新任务。

## 5. 星星

- 系统只有一种货币：星星。
- `starBalance` 表示当前可用余额。
- `lifetimeStarsEarned` 表示从开始使用产品以来累计获得的全部奖励星星，只增不减。
- 基础奖励和提前加成都增加余额与累计获得值。
- 兑换扣减余额，不影响累计获得值；兑换取消时退款，也不影响累计获得值。
- 家长可以手动调整余额，必须填写原因；手动调整不影响累计获得值。
- 星星余额不能为负。
- 每次变动写入不可修改的星星流水，发奖和兑换必须使用事务与幂等键。
- 每日目标默认 12 星，家长可按孩子调整。
- 今日圆环显示“今日任务所得星星 / 每日目标”；提前奖励计入今日所得，超过目标时显示实际数值并保持满环。

## 6. 航图与星球点亮

- 航图固定包含水星、金星、地球、火星、木星、土星、天王星和海王星，并复用儿童端统一底部导航。
- “航行能量”直接使用 `lifetimeStarsEarned`，不是第二种货币；“可用星星”使用 `starBalance`。
- 家长可以为每颗星球配置点亮所需的历史累计星星与点亮加送星星，后续星球的门槛不得低于前一颗。
- 默认点亮门槛依次为 0、60、120、180、360、520、720、960；默认点亮奖励依次为 5、8、10、12、15、18、20、25。
- 达到门槛后星球自动点亮且永久保留。加送星星只发放一次，同时增加当前余额与历史累计获得值，并写入带幂等键的星星流水。
- 修改已点亮星球的门槛或奖励不会撤回、补差或重复发奖；实际发放值保留为历史快照。
- 新点亮的星球会在孩子下次进入任务首页时自动弹出一次点亮提示，展示当前星宠、对应星球图片和实际加送星星。
- “去航图看看”和“留在任务页”都会持久化本次提示已读状态，刷新、重新登录或更换设备后均不再重复弹出；前者进入航图，后者留在任务首页。
- 点亮提示与航程介绍分别记录。关闭提示后，孩子仍可从航图点击已点亮星球查看对应的航程介绍页。
- 未点亮星球使用同一张彩色素材，通过 CSS 灰度和透明度呈现锁定状态，不维护重复的灰色图片。
- 足迹和每日目标仍只统计任务所得，不把星球点亮奖励计入当天任务得分。

## 7. 星愿兑换

固定分类与固定插图：

- 活动体验
- 娱乐时间
- 物品消费

旧的“游戏”和“电视”合并为“娱乐时间”；历史兑换记录继续保留且统一按新分类展示。

家长可以在每个分类下配置多个星愿，字段包括孩子、分类、名称、兑换星数、可重复/一次性、排序与启用状态。

- 余额不足时不可兑换。
- 孩子确认兑换后，服务端在事务内重新校验余额、扣减星星并创建兑换记录。
- 状态包括待安排、已安排、已完成、已取消。
- 取消时自动退还星星。
- 同一星愿处于待安排或已安排时不能重复兑换。
- 可重复星愿在已完成或已取消后可以再次兑换。
- 一次性星愿完成后不再显示；取消后恢复可兑换。

## 8. 足迹

- 孩子端默认展示当前自然周（周一到周日）。
- 未来日期显示短横线；其余日期显示当天通过任务获得的星星。
- 点击日期展示已完成任务及所得奖励，基础奖励和加成奖励合并显示。
- 孩子端不展示失败、放弃和未完成记录；家长端可以查看。
- 足迹统计只包含任务奖励，不包含手动调整、兑换、退款。

## 9. 后台范围

家长端：

- 切换孩子、资料管理、昵称、每日目标、重置引导、设备列表、全部退出。
- 循环与一次性任务配置、排序、启用和归档。
- 星愿配置、兑换处理。
- 星星余额、流水、带原因的手动调整。
- 航图点亮门槛、一次性加送星星、已点亮状态与实际发放值。
- 任务历史及日/周/月统计，包括完成、未完成、超时、放弃、执行时长、基础/加成星星、兑换与退款。

超级管理后台：

- 家庭、家长、孩子账号的创建、编辑、停用、重置和绑定。
- 查看全产品数据与审计日志。
- 统计家庭、家长、孩子、DAU/WAU/MAU、引导完成、任务完成率、限时成功/超时/放弃、星星发放/消耗/退款和兑换。

## 10. AI 育儿助手

- DeepSeek API Key 由家庭自行配置，服务端加密保存，前端不回显完整值。
- 自然语言任务顾问生成结构化草案；只有家长确认后才创建任务。
- 星星与兑换校准只提供建议，不自动修改任务奖励、余额或星愿价格。
- 智能排班只处理家长明确勾选的任务，并以家长设置的可用时间和负荷上限为硬约束。
- AI 建议必须通过字段契约和服务端领域校验；校验失败不保存、不应用。
- 家长可以为任务设置一般、新内容、复习、混合类型，以及每周次数和最小间隔。
- AI 不使用羞辱、比较、威胁、惩罚或扣除已获得星星的策略；星星奖励努力、投入和练习过程。
- AI 不提供医疗、心理或发育诊断，遇到相关担忧应建议咨询合格专业人员。
- 所有应用动作写入审计日志，保留提示词版本和建议单编号。
